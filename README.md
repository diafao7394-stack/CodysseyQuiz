# CodysseyQuiz

CodysseyQuiz는 코디세이 실습에서 만든 Python 콘솔 역사 퀴즈입니다. 기본 역사 문제 5개가 포함된 4지선다형 퀴즈를 풀고, 직접 만든 문제를 추가할 수 있습니다.

## 실행 방법

실행에는 Python 3 표준 라이브러리만 사용합니다. Git이 설치되어 있다면 터미널에서 아래 명령을 순서대로 실행하세요.

```powershell
git clone https://github.com/diafao7394-stack/CodysseyQuiz.git
cd CodysseyQuiz
python Quiz.py
```

프로그램이 시작되면 메뉴 번호를 입력해 기능을 선택합니다. Windows에서 IDLE을 사용하는 경우 `Quiz.py`를 열고 `F5`를 눌러 실행할 수도 있습니다.

## 주요 기능

| 메뉴 | 설명 |
| --- | --- |
| 1. 퀴즈 풀기 | 등록된 문제 수 범위에서 풀 문제 수를 고릅니다. 선택한 수만큼 등록 순서대로 출제하고, 각 답의 정오답과 최종 점수를 표시합니다. |
| 2. 퀴즈 추가 | 질문, 선택지 4개, 정답 번호를 입력해 새 문제를 추가합니다. |
| 3. 퀴즈 목록 | 등록된 문제의 질문을 번호순으로 확인합니다. |
| 4. 최고 점수 | 한 번의 퀴즈에서 가장 많이 맞힌 문제 수를 확인합니다. |
| 5. 종료 | 프로그램을 종료합니다. |

예를 들어 문제가 5개일 때 메뉴에서 `1`을 선택하고 문제 수에 `3`을 입력하면, 앞의 3문제만 풀게 됩니다. 2문제를 맞히면 `최종 점수: 2/3`이 표시됩니다. 전체 문제를 풀려면 현재 등록된 문제 수를 입력하세요. 최고 점수는 한 회차에서 맞힌 문제 수를 기준으로 기록합니다.

## 데이터 저장 방식

첫 실행에는 기본 역사 문제 5개로 시작합니다. 문제를 추가하거나 최고 점수를 처음 기록하거나 갱신하면, 전체 퀴즈 목록과 최고 점수를 `Quiz.py`와 같은 폴더의 `state.json`에 저장합니다. 다음 실행에서는 이 파일을 읽어 저장된 문제와 최고 점수를 불러옵니다.

### JSON을 선택한 이유와 한계

JSON은 문제별 질문, 선택지 목록, 정답 번호와 전체 최고 점수를 계층적으로 표현할 수 있습니다. 키 이름으로 각 값의 의미를 파악할 수 있고, Python 표준 라이브러리로 읽고 쓸 수 있으며, 파일 하나를 복사해 다른 환경으로 옮기기도 쉽습니다. CSV는 표 형태의 데이터에 적합합니다. CSV로 같은 데이터를 저장하려면 선택지 4개를 개별 열로 정의하고 최고 점수를 저장할 위치를 별도로 정해야 합니다.

현재 방식은 시작할 때 파일 전체를 파싱해 메모리에 올리고, 문제 하나를 추가해도 전체 목록을 다시 파일에 씁니다. 데이터가 커지면 메모리 사용량과 읽기·쓰기 시간이 늘어납니다. 문제 수가 많거나 검색과 개별 수정이 잦다면 SQLite에 문제와 점수를 저장해 필요한 행만 조회하고 변경할 수 있습니다.

### 자동 백업과 수동 복구

새 상태를 저장하기 전에 직전에 정상적으로 불러왔거나 저장한 퀴즈와 점수를 같은 폴더의 `state.backup.json`에 자동으로 보관합니다. 백업은 한 세대만 유지합니다. 저장 파일이 없는 상태로 시작하면 두 번째 저장부터 백업이 생성됩니다. 손상된 저장 파일로 인해 기본 문제로 시작한 경우에는 첫 저장 시 기존 백업을 보존합니다.

백업 파일이 있다면 프로그램을 종료한 뒤, `Quiz.py`가 있는 폴더에서 아래 PowerShell 명령을 실행하세요. 다시 실행하면 백업에 있던 문제와 최고 점수를 불러옵니다.

```powershell
Copy-Item -LiteralPath .\state.backup.json -Destination .\state.json -Force
```

## 코드 및 저장소 구조

- `Quiz`는 개별 문제의 질문, 선택지, 정답을 보관합니다. `show_question()`으로 문제를 출력하고 `is_correct()`로 정답을 판정합니다.
- `QuizGame`은 메뉴와 퀴즈 진행, 채점, 데이터 저장 및 불러오기를 담당합니다. `select_question_count()`는 풀 문제 수를 입력받아 검증하고, `play_quiz()`는 그 수만큼 출제합니다. `show_quiz_list()`는 등록된 문제의 질문을 출력합니다.

클래스를 사용하면 문제 데이터와 정답 판정은 `Quiz`에, 퀴즈 목록과 최고 점수처럼 실행 중 바뀌는 상태는 `QuizGame`에 모을 수 있습니다. 함수 중심으로 구현할 경우 각 함수가 필요한 데이터를 인자로 받아 넘기거나 공용 상태를 참조해야 합니다. 이 프로젝트에서는 같은 속성과 동작을 가진 문제를 여러 개 만들고, 하나의 `QuizGame` 객체에서 메뉴를 실행하는 동안 상태를 관리하도록 클래스로 구성했습니다.
